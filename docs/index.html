Ignite 2026 security tracker

Every security announcement made at Microsoft Ignite 2026 (17 to 20 November), each checked against its own Microsoft source and written for the people who run Defender, Sentinel, Entra and Purview day to day. The Book of News, the blog posts and the sessions each tell part of the story. What I need is the part that changes a tenant, and what to do about it on Monday.

What it covers and how status is verified

What it covers. Agentic SOC and Security Copilot, Microsoft Perception and MDASH, Microsoft Sentinel, Defender XDR and the Defender workloads, Defender for Cloud, security for AI, Entra, Purview and DevSecOps. One row per announcement: status, availability, the primary Microsoft source, the Learn page, related sessions, one line on what changes and one line on what I would do the Monday after.

How status is verified. The status (GA, public preview, preview, private preview, announced) is Microsoft's own wording in the primary source, never a recap or a third-party post. Preview means the source says preview without saying public or private. Announced means Microsoft named it without a preview or GA status. Each row carries the date it was last checked against that source, and every link is checked before a release. When Microsoft changes a status, the row changes with it.

Not affiliated with Microsoft. This is a personal tracker, maintained by Pouyan Khabazi. Product names belong to Microsoft. If you find a wrong status or a dead link, open an issue with the source.
